Amazon Crawler 可执行抓取路径与调用方法

整理自当前代码入口，覆盖命令行模式、HTTP API 模式、品牌巡查、链接巡检、ASIN 评论统计和评价抓取。更新时间：2026-07-03。

公共前置条件

所有模式都从项目根目录执行，并先经过 main.go 中的配置、robots、MySQL、网络和信号初始化流程。

  • 配置文件默认是 config.yaml，也可以通过 -c 指定。
  • 程序启动时会连接 MySQL，并从数据库读取 Cookie、任务或写入结果。
  • config.yaml 的 exec.enable 至少需要开启一个模块，否则 init_config 会直接退出。
  • 所有 Amazon 页面请求都会经过 robots.txt 检查和当前浏览器指纹请求头。

构建与基础运行

powershell -ExecutionPolicy Bypass -File .\scripts\init.ps1 -Build
go run . -c config.yaml
.\amazon-crawler.exe -c config.yaml

如果同时传入多个模式参数，实际执行优先级为：-brand、-link-file、-review-url、-asin、-serve、默认关键词循环。

1. 默认关键词循环抓取

适用场景 从数据库 amc_category 读取关键词，按配置循环执行搜索、商品页解析和卖家详情抓取。

go run . -c config.yaml
.\amazon-crawler.exe -c config.yaml

执行链：

main
  app.start
  searchStruct.main
  productStruct.main
  sellerStruct.main

配置控制项主要位于 config.yaml 的 exec.enable、exec.loop 和 exec.search_priority。

2. HTTP 关键词任务抓取

适用场景 外部系统提交关键词任务，服务端写入 amc_category，后台 Worker 消费待执行任务。

启动服务

go run . -c config.yaml -serve :8080
.\amazon-crawler.exe -c config.yaml -serve :8080

提交关键词任务

curl -X POST http://127.0.0.1:8080/api/crawl ^
  -H "Content-Type: application/json" ^
  -d "{\"keywords\":[\"nike\",\"adidas\",\"puma\"]}"

执行链：

POST /api/crawl
  handleCrawl
  insertKeywordTask
  taskNotify
  TaskWorker.processPendingTasks
  ExecuteCrawlWithStatus
  crawlSearchInMemory
  crawlProductsFromMemory
  fetchSellerDetails
  batchSaveAll

如果启动时带 -serve-only，服务不会启动关键词任务消费者。此时 /api/crawl 仍会写入任务，但不会在当前进程里继续抓取。

3. HTTP ASIN/链接实时巡检

适用场景 小批量实时巡检商品链接或 ASIN，返回商品标题、价格、优惠、评分、评论数、徽标等结构化 JSON。

启动 API-only 服务

go run . -c config.yaml -serve 127.0.0.1:8080 -serve-only

调用接口

curl -X POST http://127.0.0.1:8080/api/asin-inspection ^
  -H "Content-Type: application/json" ^
  -H "X-Crawler-Token: <token>" ^
  -d "{\"job_id\":\"workbench-123\",\"domain\":\"www.amazon.com\",\"items\":[{\"asin\":\"B0FNMPQSJC\"},{\"url\":\"https://www.amazon.com/dp/B0DWWWP4FF?th=1\"}],\"options\":{\"include_offer\":true}}"

执行链：

POST /api/asin-inspection
  handleASINInspection
  buildASINInspectionItems
  NewLinkInspector("", domain, "")
  LinkInspector.inspectItem
  linkInspectionResultToAPIItem
  • 单次请求最多 50 条。
  • 当前代码中 CRAWLER_API_TOKEN 校验在 /api/asin-inspection 执行；设置后需要传 X-Crawler-Token。
  • 单项失败会在该项返回 status=failed 和 error_message，不会中断其他项。

4. 命令行链接巡检

适用场景 批量读取文本文件中的 ASIN 或 Amazon 商品链接，输出 Excel 巡检结果。

输入文件示例

https://www.amazon.com/dp/B0FNMPQSJC
B0DWWWP4FF

调用方法

go run . -c config.yaml -link-file .\asins.txt -domain www.amazon.com -link-output .\output\link_inspection.xlsx
.\amazon-crawler.exe -c config.yaml -link-file .\asins.txt -domain www.amazon.com -link-output .\output\link_inspection.xlsx

执行链：

main
  NewLinkInspector(linkFile, domain, linkOutput)
  LinkInspector.Run
  loadLinkInspectionItems
  inspectItem
  writeInspectionXLSX

如果不指定 -link-output，默认输出到 output/link_inspection_时间.xlsx。

5. 命令行评价抓取

适用场景 抓取单个商品页和评价第一页中的可见评价，下载评价图片和顾客图片区图片。

按商品链接调用

go run . -c config.yaml -review-url "https://www.amazon.com/dp/B0FNMPQSJC" -review-output .\output\reviews_B0FNMPQSJC.csv -review-image-dir .\output\reviews_B0FNMPQSJC_images

按 ASIN 调用

go run . -c config.yaml -review-url B0FNMPQSJC -domain www.amazon.com

执行链：

main
  NewReviewScraper(reviewURL, reviewOutput, reviewImageDir)
  ReviewScraper.Run
  scrapeFirstPage
  parseReviewItems
  downloadReviewImages
  exportCSV
  downloadCustomerPhotos
  exportCustomerPhotosCSV
  • 默认 CSV：output/reviews_ASIN_时间.csv。
  • 默认图片目录：与 CSV 同名并追加 _images。
  • 顾客图片区清单默认是 reviews_ASIN_时间_customer_photos.csv。

6. 命令行 ASIN 评论统计

适用场景 批量抓取 ASIN 的评分和评论数，输出 CSV。

go run . -c config.yaml -asin B0FNMPQSJC,B0DWWWP4FF -domain www.amazon.com
.\amazon-crawler.exe -c config.yaml -asin B0FNMPQSJC,B0DWWWP4FF -domain www.amazon.com

执行链：

main
  NewASINScraper(asin, domain)
  ASINScraper.Run
  scrapeASIN
  extractReviewCount
  extractRating
  exportCSV

如果 -domain 为空且使用 -asin，当前代码默认域名为 www.amazon.com.mx。结果默认写入 output/asins_时间.csv。

7. 品牌巡查

适用场景 从 available_brand_domains 读取待巡查品牌，优先使用已有 ASIN，否则搜索品牌名，再访问商品页提取卖家并保存店铺信息。

go run . -c config.yaml -brand
.\amazon-crawler.exe -c config.yaml -brand

执行链：

main
  brandMain
  processBrandBatch
  brandStruct.process
    processWithASIN 或 processWithSearch
    fetchProductPage
    fetchSellerInfo
    saveToAmazonShop
  • 读取表：available_brand_domains。
  • 写入表：tb_amazon_shop，并更新品牌巡查状态。
  • 配置项：brand.max_asins、brand.batch、brand.loop。

辅助 HTTP 接口

方法 路径 用途 调用示例
GET /api/status 统计 amc_category.task_status 中待执行、已完成、失败任务数量。 curl http://127.0.0.1:8080/api/status
GET /health 健康检查，返回 {"code":0,"message":"ok"}。 curl http://127.0.0.1:8080/health

常用参数速查

参数 说明 示例
-c 配置文件路径，默认 config.yaml。 -c config.yaml
-serve 启动 HTTP 服务，值为监听地址。 -serve :8080
-serve-only 只启动 API，不启动关键词任务消费者。 -serve 127.0.0.1:8080 -serve-only
-domain 指定 Amazon 域名，链接巡检、ASIN 模式和评价抓取常用。 -domain www.amazon.com
-brand 启动品牌巡查模式。 -brand
-link-file 启动链接巡检模式，读取一行一个 ASIN 或商品链接的文本文件。 -link-file .\asins.txt
-link-output 链接巡检 XLSX 输出路径。 -link-output .\output\link_inspection.xlsx
-review-url 启动评价抓取模式，传 Amazon 商品链接或 ASIN。 -review-url B0FNMPQSJC
-review-output 评价抓取 CSV 输出路径。 -review-output .\output\reviews.csv
-review-image-dir 评价图片下载目录。 -review-image-dir .\output\review_images
-asin 启动 ASIN 评论统计模式，多个 ASIN 用英文逗号分隔。 -asin B0FNMPQSJC,B0DWWWP4FF
